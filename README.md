## Featured Projects

### 〰️ [SeismicApp — Interactive Seismic Acquisition Simulator](YOUR_REPOSITORY_LINK)

An interactive browser-based application for exploring seismic-acquisition concepts.

Users can configure shots and receivers and observe how acquisition geometry affects synthetic seismic responses in real time. The application includes visual tools for concepts such as acquisition fold, source-receiver offsets, reflectivity, and first-order free-surface ghost effects.

- Fully offline and lightweight
- Built with HTML, CSS, and JavaScript
- Interactive shot and receiver geometry
- Synthetic seismic trace visualization
- Educational tools for seismic acquisition and wave propagation

A machine-learning project that uses neural-network autoencoders to identify low-dimensional intrinsic state variables in complex materials.

- Representation learning for physical systems
