## Selected projects

### [SeismicApp](https://github.com/frasera00/SeismicApp) — Interactive seismic acquisition simulator

An interactive browser application for exploring seismic acquisition geometry and its effect on synthetic seismic responses.

The application lets users configure sources and receivers, inspect acquisition fold, visualize synthetic traces and examine effects such as source-receiver offsets, reflectivity and first-order free-surface ghosts. It was built with HTML, CSS and JavaScript and runs entirely in the browser.

- [Live demo](https://frasera00.github.io/SeismicApp/)
- [Repository](https://github.com/frasera00/SeismicApp)

### [Seismic Gather QC](https://github.com/frasera00/seismic-quality-intelligence) — Unsupervised anomaly detection

A Python project for detecting anomalous traces in synthetic prestack-style seismic gathers.

The project uses an Isolation Forest trained only on normal traces, combining signal-based features with unsupervised learning to flag traces that depart from the expected behaviour. It is a practical exploration of how classical QC criteria and machine learning can complement each other in seismic data quality control.

- [Repository](https://github.com/frasera00/seismic-quality-intelligence)

### [Movie Recommendation Web App](https://github.com/frasera00/Movie_recommendation_web_app) — LLM and RAG

A web application that uses retrieval-augmented generation to provide movie recommendations based on user preferences.

The project combines semantic search, a vector database and an LLM to retrieve relevant information before generating a response. It was an opportunity to work with the practical parts of building an AI application: retrieval, prompting, response quality and interface design.

- [Repository](https://github.com/frasera00/Movie_recommendation_web_app)

### [PyISV](https://github.com/frasera00/PyISV) — Intrinsic state variables with autoencoders

A research-oriented project on representation learning for molecular dynamics data.

The project applies autoencoders to identify low-dimensional intrinsic state variables in complex material systems. It connects high-dimensional simulation data with physically meaningful descriptors, with applications to metallic nanoclusters and related systems.

- [Repository](https://github.com/frasera00/PyISV)

### [GrafTo](https://github.com/frasera00/GrafTo) — Polymer-grafted surfaces

Python tools for building, analysing and visualizing coarse-grained molecular dynamics systems with polymer-grafted surfaces.

The project supports the construction of simulation-ready structures and the inspection of polymer conformations, interfacial morphology and structural observables. It reflects my earlier research work on complex materials and molecular simulation.

- [Repository](https://github.com/frasera00/GrafTo)

### [World Cup Monte Carlo Simulation](https://github.com/frasera00/World_cup_simulation) — Probabilistic modelling

A Monte Carlo simulation of football tournament outcomes.

The project uses repeated simulations to explore uncertainty, scenario analysis and outcome distributions. It is a smaller project, but it reflects my interest in probabilistic thinking and statistical modelling.

- [Repository](https://github.com/frasera00/World_cup_simulation)
